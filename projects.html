Wanderlust – Travel Stay Booking Platform

Tech Stack

Node.js, Express.js, MongoDB, EJS, Passport.js, Cloudinary, Render

Description

Wanderlust is a full-stack travel stay booking platform inspired by Airbnb. Users can browse properties, create listings, upload images, leave reviews, and securely authenticate before managing their listings.

Key Features

  • User Registration & Login
  • Authentication using Passport.js
  • CRUD Operations for Listings
  • Property Reviews & Ratings
  • Cloudinary Image Upload
  • MongoDB Atlas Database
  • Responsive Design

Unilearn – Online Learning Platform

Tech Stack

React, Node.js, Express.js, MongoDB, Socket.io, WebRTC, Tailwind CSS, JWT

Description

Unilearn is a MERN Stack based online learning platform where students can enroll in courses, watch lectures, track progress, participate in discussions, and interact with instructors in real time.

Key Features

  • User Authentication with JWT
  • Course Enrollment
  • Progress Tracking
  • Real-Time Discussions
  • Video Lectures
  • Course Ratings & Reviews
  • Responsive React UI
